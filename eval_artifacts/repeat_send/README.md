# 재발송 회귀셋 (2026-09-26 ~ 10-25)

재발송(이미 보낸 사건의 재탕)을 막는 판정을 바꿀 때마다 **이 셋 전체**에서 몇 건을 막고
몇 건을 잃는지 함께 보고한다. 사고 하나를 재생해 "오탐 0"을 확인하는 것으로는 다음 재탕이
다른 경계로 새는 것을 못 본다(`docs/2026-10-25-repeat-send-root-cause-review.md` §3).

## 만든 방법

- 모집단: `delivery_log.jsonl`의 9/26~10/25 발송 497건.
- 의심 쌍: 앞선 14일 발송 중 하나라도 `issue_continuity.same_issue` 매칭이거나,
  `cross_day_audit`의 LLM 비교 대상이거나, 제목 유사도 0.5 이상인 발송 **256건**.
  나머지 241건은 앞선 발송과 연결이 없다(재탕일 수 없다고 본다).
- 판정: 사람 1인이 카드 제목·요약과 앞선 카드(유사도 상위 3건)를 읽고 붙였다. LLM 0회.

예정→공식 발표)는 `note`에 이유를 적었다. 판정자가 한 명이라 경계 몇 건은 달리 볼 수 있다.
